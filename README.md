# 🏛️ Sovereign OS — Multi-Asset Institutional Trading & Office Application

Sovereign OS is a high-performance, modern institutional trading terminal and office management platform built with React 19, TypeScript, Vite, and Tailwind CSS.

## ✨ Features

- 📈 **Real-Time Trading Terminal**: Interactive Candlestick / Area charts with depth indicators, timeframe selector (1M, 5M, 1H, 1D), and live streaming indicators.
- ⚡ **Institutional Order Execution**: Limit, Market, Stop-Loss, and Take-Profit orders with instant execution feedback and real-time leverage selector (1x - 100x).
- 💼 **Portfolio & Asset Management**: Live balance, PnL analytics, open positions monitoring, and asset breakdown charts.
- 🌐 **Multi-Asset Coverage**: Crypto (BTC, ETH, SOL), Forex (EUR/USD, GBP/USD), and Commodities (Gold, Silver, Crude Oil).
- 🌍 **Multi-Language Support**: Seamless instant toggle between English and Turkish (Türkçe).
- 🛡️ **Enterprise Security & Guards**: Protected routing, session management, Google Identity integration, and zero credential leakage.
- 🎨 **Sleek Cyber-Dark Theme**: High-contrast, accessibility-tested trading aesthetics with smooth transitions.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/SEVKET210/sovereign-os.git
cd sovereign-os
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
The application will launch at `http://localhost:3000`.

---

## 🛠️ Scripts

- `npm run dev`: Launch Vite development server with HMR.
- `npm run build`: Compile TypeScript and build production bundle with Vite.
- `npm run lint`: Fast linting using Oxlint.
- `npm test`: Run automated end-to-end integration and sanity test suites.
- `npm run preview`: Preview the production build locally.

---

## 📦 Deployment

Optimized for instant zero-configuration deployment on **Vercel** and **Netlify**:
- `vercel.json` included for single-page application (SPA) client-side routing.
- `public/_redirects` included for Netlify routing compatibility.
